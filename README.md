# Blessed Barbearia

Site da Blessed Barbearia, em Arcoverde–PE, feito com HTML, CSS e JavaScript puros.

**Site:** https://traaaaaaaaaanks.github.io/Projeto-Barbearia/

**Repositório:** https://github.com/TraaaaaaaaaaNKS/Projeto-Barbearia

## Estado atual

Versão preta e prateada com acabamento metálico, WhatsApp, galeria ampliável com gestos no celular e mapa incorporado. A branch `main` alimenta o GitHub Pages. A versão dourada permanece em `backup/paleta-dourada`.

## Documentação

- [Guia completo](docs/GUIA.md): funcionalidades, edição, publicação, recuperação e testes.
- [Histórico de alterações](docs/CHANGELOG.md): mudanças e commits de referência.

## Executar

Abra `index.html` no navegador ou use um servidor estático, como o Live Server do VS Code. Não há dependências para instalar. Fotos externas e mapa precisam de internet.
